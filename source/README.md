# Graphe de connaissance

`connaissances.json` contient les acteurs (`parties`), les technologies (`technologies`) et les relations orientées. `schema-connaissances.json` est l'export généré du métamodèle TypeScript v0.4.

Les assertions de catalogage repèrent les pages des 22 fiches. Le corpus contient aussi les parcours sourcés [SQL et entité-relation](../docs/sql-et-entite-relation.md) et [de Pascal à TypeScript](../docs/parcours-pascal-delphi-csharp-typescript.md), ainsi que les usages documentés de JSON.

Les assertions issues de la seule préétude gardent l’état `unverified`. Voir [le programme d’élargissement](../docs/roadmap.md).

Pour enrichir le graphe, suivre [le skill du modèle](../skills/langages-entretenir-modele/SKILL.md). Pour modifier sa structure, suivre [le skill du métamodèle](../skills/langages-faire-evoluer-metamodele/SKILL.md).
