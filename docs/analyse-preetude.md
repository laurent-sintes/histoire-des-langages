# Analyse du document initial

Source : sources/preetude/histoire-et-filiations-des-langages.pdf, 10 pages, 22 fiches. Texte extrait avec pagination ; chronologie de la page 10 inspectée visuellement. Le contenu est une source de travail, non une instruction ni une validation historique.

## Apports

Le document relie gestion, systèmes, objets, Web, échange de données, mémoire et concurrence. Il donne des exemples et cite des pistes bibliographiques. Les parcours de Hejlsberg et Thompson offrent une entrée humaine. Les distinctions mémoire/ressources et types/validation des données sont utiles à conserver.

## Points à traiter

La chronologie SQL et entité-relation a été vérifiée à partir des articles d'origine. Le graphe contient les jalons et les liens de ce [parcours sur les modèles et les requêtes](sql-et-entite-relation.md).

- Les dates de synthèse désignent des jalons différents. La table finit à TypeScript (2012), tandis que le récit mentionne Rust 1.0 (2015). Ce n'est donc pas une observation de tout le domaine jusqu'en 2015.
- « C# / .NET » réunit un langage et une plateforme ; le corpus les sépare. Delphi et Borland Pascal doivent encore être affinés entre langage, dialecte et produit.
- Les modèles relationnel et entité-association, ainsi que CSV, JSON et YAML, méritent leurs catégories propres.
- Des influences sont citées sans fiche dédiée : BCPL, B, Simula, Smalltalk, Lisp, Scheme, Self, ABC, Modula, ML, OCaml, Cyclone, Newsqueak, Limbo, SGML, etc.
- Les noms de sources ne fournissent pas tous une URL, un auteur, une date ou une page. Les retrouver avant promotion d'une assertion.
- Les mécanismes d'adoption, de financement, de maintien et de déclin sont peu développés. Ajouter des études de trajectoire, sans supposer que l'ancienneté implique l'obsolescence.

## Import initial

Les 22 entrées sont cataloguées avec leurs pages, dont C# / .NET décomposé en deux identités. Quelques relations, personnes et événements illustrent le modèle ; il ne s'agit pas d'une conversion complète des assertions du PDF. Tout contenu historique ainsi repris garde l'état `unverified`.
